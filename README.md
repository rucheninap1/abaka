# Математическая абака

Командная игра для математического кружка: темы × задачи, баллы за верные ответы, бонусы за закрытые линии, живое табло.
Ведущая создаёт игру прямо на сайте и отправляет командам **одну ссылку**. Команды сами вводят название и получают личную ссылку. Ответы проверяются автоматически, а задачи на **разрезание** и геометрические — **интерактивные**: команда рисует разрезы мышью или пальцем.

**Сайт:** https://rucheninap1.github.io/abaka/

## Как провести игру (для ведущей)

1. Откройте сайт → **Создать игру**: название, время, набор задач (готовый или свой) → «Создать игру».
2. Нажмите «Копировать ссылку» в блоке «Ссылка на игру для команд» и отправьте её командам.
3. Команды открывают ссылку, вводят название — и появляются в списке «Команды». Личная ссылка каждой команды показана в этом списке на случай, если нужно продолжить с другого устройства.
4. Нажмите «Начать игру». Дальше всё автоматически: числа, текст, наборы чисел и разрезания проверяются сразу, табло и бонусы считаются сами. Вручную остаются только ответы «Вручную» и фотографии.
5. «Завершить игру» закрывает приём ответов. Ссылку пульта (с ключом ведущей) никому не передавайте — она сохраняется в списке «Мои игры» на главной.

## Как играют команды

- Открыть ссылку игры, ввести название команды. Сайт запомнит команду на этом устройстве; вернуться можно по той же ссылке.
- Внутри темы задачи сдаются по порядку, темы можно чередовать. Для обычных задач — ответ числом/словом или фото.
- Если задача не получается, её можно **пропустить** (кнопка «Пропустить задачу»): вернуться к ней нельзя, баллы за неё не начисляются, следующая задача темы открывается. Ведущая может вернуть пропущенную задачу команде в пульте.
- **Разрезание:** нажимайте на линии сетки внутри фигуры или ведите по ним пальцем — появится разрез (повторное нажатие убирает). Части раскрашиваются сами; под полем показывается только «Верно» или «Неверно», без подсказок. Неверное решение отправить нельзя, поэтому попытка не тратится. Сервер проверяет решение повторно.

## Свои задачи

При создании игры (или на пульте до старта) задачи задаются таблицей: **Тема № · Название темы · Задача № · Условие · Проверка · Правильные ответы**. Таблицу можно вставить из Google-таблицы или Excel.
Проверка: `Число`, `Текст`, `Набор чисел` (через `;`), `Вручную`, `Разрезание`. Несколько допустимых ответов разделяются `|`.
Для интерактивной задачи выберите проверку `Разрезание` и допишите в условие метку, например `[[puzzle:b1t10]]`. Доступные метки: `b1t10…b1t40`, `b2t10…b2t40`, `b3t10…b3t40`. Новые фигуры добавляются в `DEFS` в `puzzle.js` (строки из `#` — клетки, `g`/`r`/`p` — зелёная/красная/фиолетовая клетка); тот же файл находится в конце `Code.gs`.

## Устройство (один раз настроить сервер)

| Часть | Где живёт | Что делает |
|---|---|---|
| Сайт (`index.html`, `app.js`, …) | GitHub Pages | интерфейс ведущей и команд |
| Сервер (`Code.gs`) | Google Apps Script ведущей | хранит все игры в Google-таблице (создаётся сама), принимает и проверяет ответы, считает баллы |

Если сервер ещё не развёрнут: script.google.com → Новый проект → вставить весь `Code.gs` → **Развернуть → Новое развертывание → Веб-приложение** (выполнять от имени: Я; доступ: Все) → скопировать адрес `/exec` и вписать его в `config.js` (`window.ABAKA_API`) либо открыть сайт один раз по ссылке `…/abaka/#api=<адрес /exec>`. Таблица и папка для фото создаются автоматически при первом обращении.
Обновление сервера: заменить код → **Развернуть → Управление развертываниями → карандаш → Новая версия**.
Необязательно: чтобы создавать игры могла только ваша ведущая, добавьте в «Свойства скрипта» ключ `creator` со своим кодом — сайт будет спрашивать его при создании игры.

## Если что-то не работает

- **«Подключение к серверу»** — сайту неизвестен адрес сервера (см. выше).
- **«Сервер ответил не так, как ожидалось»** — у веб-приложения должен быть доступ «Все»; после правки кода нужна новая версия развёртывания.
- **«Игра не найдена»** — неверная или обрезанная ссылка.
- Школьный Google Workspace может запрещать внешние веб-приложения — используйте личный аккаунт.
