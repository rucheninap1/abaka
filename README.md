# Математическая абака

Командная игра для математического кружка: темы × задачи, баллы за верные ответы, бонусы за закрытые линии, живое табло.
Задачи на **разрезание** и геометрические — **интерактивные**: команда рисует разрезы прямо на сайте (мышью или пальцем), а сайт и сервер сами проверяют решение.

**Сайт:** https://rucheninap1.github.io/abaka/ (откроется после настройки ниже)

## Как это устроено

| Часть | Где живёт | Что делает |
|---|---|---|
| Сайт (`index.html`, `app.js`, `puzzle-ui.js` …) | GitHub Pages | интерфейс команд и пульта ведущей |
| Сервер (`Code.gs`) | **ваш** Google-аккаунт (Apps Script) | хранит игру в вашей Google-таблице, принимает ответы, считает баллы, повторно проверяет разрезания |
| Таблица и папка с фото | ваш Google Диск | закрытые, детям не открываются |

GitHub Pages — статический хостинг, поэтому общее хранилище (ответы команд, табло) остаётся в вашем Google-аккаунте, как и раньше. Ничего нового регистрировать не нужно.

## Установка (один раз, ~10 минут)

1. Откройте https://script.google.com/ → **Новый проект**, назовите «Математическая абака».
2. Откройте `Code.gs` в этом репозитории → кнопка **Raw** → скопируйте **весь** текст → вставьте в файл `Код.gs` проекта вместо старого содержимого → сохраните.
3. В списке функций выберите **setup** → **Выполнить** → разрешите доступ к таблицам и Диску. Скрипт создаст закрытую таблицу и папку для фотографий. (При обновлении кода `setup` безопасно запускать повторно — данные не затрагиваются.)
4. **Развернуть → Новое развертывание → Веб-приложение**: «Выполнять от имени» — *Я*, «У кого есть доступ» — *Все*. Нажмите «Развернуть».
5. Выберите функцию **showLinks** → **Выполнить** → в журнале найдите строку **«ВЕДУЩАЯ (секрет)»** и откройте ссылку. Сохраните её в закладки. Это пульт ведущей; детям её не передавайте.
6. В пульте раскройте «Настройки игры и ссылки команд»: **3 темы × 4 задачи**, время, названия команд → «Сохранить настройки».
7. Нажмите «Открыть таблицу задач и ответов», на листе **«Задачи»** очистите все ячейки, вставьте в A1 содержимое файла `Zadachi_3x4.tsv` (там уже все 12 интерактивных задач).
8. Во «Ссылки для подключения» каждой команде выдайте **только её** ссылку. Нажмите «Начать игру».

Ссылка команды выглядит так: `https://rucheninap1.github.io/abaka/#api=…&team=…` — адрес сервера уже внутри, больше ничего вводить не нужно. Секретный ключ находится после `#` и на сервер сайта GitHub не передаётся.

## Как играют команды

- Команда открывает свою ссылку, выбирает задачу (10, 20, 30, 40 баллов). Внутри темы задачи сдаются по порядку, темы можно чередовать.
- **Разрезание:** нажимайте на линии сетки внутри фигуры или ведите по ним пальцем — появится разрез (повторное нажатие убирает). Части раскрашиваются сами, под полем сразу видно, что не так («Частей сейчас 2, нужно 3»). Кнопки «Отменить» и «Очистить». Черновик сохраняется в браузере.
- Когда решение верное, появляется зелёная плашка и кнопка «Отправить решение» срабатывает. Неверное решение отправить нельзя, поэтому попытка не тратится — можно экспериментировать. Сервер проверяет решение повторно.
- Для обычных задач (число, текст, набор чисел, вручную с фото) всё работает как раньше.

## Интерактивные задачи из листка

| Задача | Что проверяется |
|---|---|
| Блок 1 (10–40) | разрезание на 3 равные (одинаковые по форме) части |
| Блок 2 (10–40) | разрезание на 4 равные части |
| Блок 3, 10 | три **разных** разрезания на две одинаковые части, по одному на картинке |
| Блок 3, 20 | закрасить одну клетку, остальное — на две одинаковые части |
| Блок 3, 30 | 4 одинаковые части, в каждой по одной клетке каждого цвета |
| Блок 3, 40 | 12 частей по 5 клеток, в каждой ровно одна зелёная клетка, не менее 11 разных фигур |

Одинаковые — значит совпадающие наложением с поворотом и отражением. Все 12 задач проверены решателем: решение есть, проверка его принимает.

## Свои задачи

На листе «Задачи» в столбце **E «Проверка»** выберите **Разрезание**, а в столбец **D «Условие»** допишите метку, например `[[puzzle:b1t10]]`. Метка выбирает фигуру из `puzzle.js`; текст перед меткой — условие, его можно менять.
Метки: `b1t10 … b1t40`, `b2t10 … b2t40`, `b3t10 … b3t40`. Остальные виды проверки (Число, Текст, Набор чисел, Вручную) — как в прежней инструкции.

Новые фигуры добавляются в `DEFS` в файле `puzzle.js` (строки из `#` — клетки, пробел — пустое место, `g`/`r`/`p` — зелёная/красная/фиолетовая клетка). Тот же файл `puzzle.js` целиком находится в конце `Code.gs` — при правке менять в обоих местах.

## Обновление

- Сайт: замените файлы в репозитории, GitHub Pages обновится за минуту.
- Сервер: замените весь код в Apps Script → **Развернуть → Управление развертываниями** → карандаш → «Новая версия» → «Развернуть». Адрес `/exec` сохраняется.

## Если что-то не работает

- **Форма «Подключение к серверу»** — открыта ссылка без `#api=…`. Возьмите ссылку из пульта или вставьте адрес `/exec` в форму.
- **«Сервер ответил не так, как ожидалось»** — в развёртывании веб-приложения должен быть доступ **«Все»**; после изменения кода нужна новая версия развёртывания.
- **Ссылка команды недействительна** — после «Новая игра» ссылки меняются, раздайте новые.
- **Не принимается тип проверки «Разрезание»** — после обновления кода один раз выполните `setup`, чтобы обновить выпадающий список в таблице.
- Школьный Google Workspace может запрещать внешние веб-приложения — согласуйте с администратором или используйте личный аккаунт.

Правила начисления баллов и бонусов, проверка фотографий, табло и завершение игры работают как раньше; правила для детей показаны на сайте в разделе «Правила игры».
