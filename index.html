Мои игры

Список хранится в этом браузере. Ссылку пульта (с ключом ведущей) никому не передавайте.

После входа сайт запомнит вашу команду на этом устройстве и покажет личную ссылку — сохраните её, чтобы продолжить с другого устройства.

Ссылка на игру для команд

Отправьте её командам — это всё, что нужно. Каждая команда введёт название и сразу получит свою личную ссылку.

Команды

Команды появляются здесь сами, как только входят по ссылке. Личную ссылку можно скопировать, если команде нужно продолжить с другого устройства.

Проверка ответов

Числовые, текстовые ответы и разрезания проверяются автоматически. Здесь остаются только ответы «Вручную» и фотографии.

Поле задач

Внутри темы ответы сдаются по порядку. У каждой задачи одна попытка.

JPG, PNG или WebP до 4 МБ. Для набора чисел используй «;»: например, 12; 14. Можно отправить только картинку.

После отправки изменить ответ может только ведущая. Пропущенную задачу вернуть нельзя.
